# Code of conduct

Treat participants with respect. Discuss the work directly, welcome reasonable questions, and give feedback that helps someone reproduce a problem or improve a contribution.

Harassment, threats, discriminatory abuse, unwanted sexual attention, deliberate disruption, and sharing another person's private information are not acceptable in project discussions or events.

Maintainers may edit or remove harmful content, close discussions, or restrict participation. They will consider the context and aim for proportionate action. Disagreement about a technical decision is welcome; personal attacks are not.

Report conduct concerns through a private contact method listed on a maintainer's GitHub profile when available. Otherwise ask for a private contact channel without posting personal details or accusations. Do not use a public issue to share private evidence.

These expectations apply to everyone, including maintainers, in spaces managed by this project and when representing it publicly.
